# Day 71 – Day 80

This folder contains my solutions for **Days 71 to 80** of the 100 Days of DSA challenge.

## ✅ Day 71

### Problem: Hash Table Using Quadratic Probing

**Description:**
Implement a hash table using quadratic probing to resolve collisions. The probing sequence follows the formula (h(k) + i²) % m.

**Concepts Used:**

* Hashing
* Collision Resolution
* Quadratic Probing
* Array Implementation

**File:**
`Day71.c`
