## ✅ Day 51

### Problem: Lowest Common Ancestor in BST

**Description:**
Find the Lowest Common Ancestor (LCA) of two nodes in a Binary Search Tree. The LCA is the lowest node in the tree that has both nodes as descendants.

**Concepts Used:**

* Binary Search Tree
* Recursion
* Tree Traversal
