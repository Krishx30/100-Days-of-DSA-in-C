This folder contains my solutions for **Days 41 to 50** of the 100 Days of DSA challenge.

## ✅ Day 41

### Problem: Queue Using Linked List

**Description:**
Implement a queue using a linked list with enqueue and dequeue operations. Elements are added at the rear and removed from the front. If a dequeue operation is performed on an empty queue, return -1.

**Concepts Used:**

* Linked List
* Queue (FIFO)
* Dynamic Memory Allocation
* Pointers

**File:**
`Day41.c`
